Terms of use

Pantry is a personal household pantry app. It keeps a list of food at home and, if you connect a Kroger account, adds items from that list to a Kroger grocery cart.

The Kroger client credentials and the tokens for a connected account stay on the server you run.

Kroger account data is used only to search products and write a cart.

This is a personal project. It is not an official Kroger product, and Kroger does not run it.

Questions about these terms: this website. The privacy policy is at /privacy.
